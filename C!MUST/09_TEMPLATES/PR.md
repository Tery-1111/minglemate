# Pull Request Template

Save this as `.github/pull_request_template.md` in your actual project repo so it auto-populates every PR.

```markdown
## What changed?

## Why?

## How?

## What could break?

## What was tested?

## What was NOT tested?

## Database changes?

## Configuration changes?

## Security implications?

## Rollback plan?
```

AI can draft most of this from the IMPLEMENT report — you review and correct it before the PR goes up. An honest "what was NOT tested" line is more valuable than a padded "everything works" claim.
